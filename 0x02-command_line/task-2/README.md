Task 2: File and Directory Management

Commands Practised

1. "mkdir -p" - Creates directories, including parent directories.
2. "touch" - Creates empty files.
3. "echo" - Writes text into files.
4. "cat" - Displays file contents.
5. "head" - Displays the first lines of a file.
6. "tail" - Displays the last lines of a file.
7. "wc -l" - Counts the number of lines.
8. "cp" - Copies files.
9. "mv" - Moves and renames files.
10. "rm" - Removes files.
11. "find" - Searches for files and directories.
12. "ls -l" - Displays file details and permissions.

Difference Between > and >>

- ">" writes text into a file and replaces existing content.
- ">>" adds text to the end of a file without removing existing content.

File Permissions

I used "ls -l" to inspect file permissions.

I observed "rw-------", which means the file owner has read and write permissions, while the group and others have no permissions.

What I Learned

I learned how to create directories and files, write and append text, copy files, move and rename files, delete files, and inspect file permissions using Linux commands.
