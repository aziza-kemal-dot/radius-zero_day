# Task 4: Bash Scripting - Automated Website Project Generator

## Objective

Create a Bash script that automatically generates a basic website project.

## Script Name

create_website.sh

## Features

- Uses Bash scripting.
- Creates a website project in the default directory.
- Accepts a custom output directory.
- Creates HTML, CSS, JavaScript, and images directories.
- Generates README files.
- Prevents overwriting an existing directory.
- Displays a success message and project location.

## Default Usage

./task-4/create_website.sh

## Custom Directory Usage

./task-4/create_website.sh "$HOME/my-custom-website"

## What I Learned

I learned how to write Bash scripts, use command-line arguments, create directories and files automatically, check whether directories exist, and give scripts execution permission.
