# Task 1: Linux Terminal Navigation & Environment Exploration

## Commands Practised

- `pwd` - Displays the current working directory.
- `whoami` - Displays the current username.
- `hostname` - Displays the computer hostname.
- `date` - Displays the current date and time.
- `ls` - Lists files and directories.
- `ls -l` - Displays files with detailed information.
- `ls -la` - Displays all files, including hidden files, with details.
- `cd ..` - Moves to the parent directory.
- `cd -` - Returns to the previous directory.
- `cd ~` - Moves to the home directory.

## What I Learned

I learned how to navigate the Linux filesystem, identify my current location and user account, inspect files and directories, and use relative and absolute paths.
