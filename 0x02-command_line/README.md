0x02: Command Line Fundamentals & Shell Scripting

Assignment Overview

This assignment introduces essential Linux command-line operations and Bash scripting.

The purpose is to learn how to navigate the Linux filesystem, manage files and directories, search for information, understand file permissions, and automate tasks using Bash scripts.

Tasks

- Task 1: Linux Terminal Navigation & Environment Exploration
- Task 2: File and Directory Management
- Task 3: Bash Scripting
- Task 4: Shell Scripting Practice

Learning Outcomes

By completing this assignment, I will develop practical skills in using Linux commands, managing files and directories, searching file contents, understanding permissions, and writing Bash scripts.
